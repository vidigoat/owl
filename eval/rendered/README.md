# Rendered panels — drawings, not photographs

Generated by `npm run panels`. Committed so `npm run eval` works on a fresh clone.

**These are not photographs and must never be counted as photographs.** They are drawn in HTML and
screenshotted, so they are missing most of what a kitchen does to an image. Four of them approximate
one difficulty each — a specular highlight, a crouching angle, an unlit room, a thumb across the
corner — because an evaluation everything passes is measuring nothing. That is still not the same as
a real photograph of a real machine.

`npm run eval` scores these and `eval/photos/` separately, under headings saying which is which, and
never averages them. **`eval/photos/` is the only number that counts**, and it is empty.

The filename is the expected answer:

```
<brand>-<kind>-panel-<code>.png     the display must read as that code
<brand>-<kind>-panel-clean.png      there must be NO code — inventing one is the worst failure here
<brand>-<kind>-plate-<model>.png    the model number must be read off the rating plate
```

Two of the ten are `clean` on purpose: a fridge showing 38°F and an oven clock reading 12:47. Both
are healthy machines covered in numbers, and a reader that calls either one a fault sends somebody
to buy a part they do not need.
