Use it yourself

The add-on is an MCP server — the same one Alexa+ would call. Anything that speaks MCP can use it, so you can talk a real repair through today, in Claude, with the same nineteen tools.

In Claude

  1. Open Settings → Connectors (on the web or in Claude Desktop).
  2. Choose Add custom connector. Name it Second Set of Hands and paste the URL above. It needs no sign-in.
  3. Start a new chat, and say what the machine is doing:
My Bosch dishwasher is showing E24 — the model is SHE3AR75UC. Talk me through it, one check at a time.
My Bosch SGE53C55UC leaves water in the bottom at the end of the program. What does the manual say?
My SHE3AR75UC says E09. Can I fix it myself?

It will ask the one check that rules out the most, cite the manufacturer's page, refuse anything behind mains wiring, and only offer a part once the diagnosis is verified. Ordering is simulated — nothing is charged.

In Cursor, VS Code, or any MCP client

{
